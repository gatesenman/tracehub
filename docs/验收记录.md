## 本轮命令与结果（1.2.2）

同一套 `node_modules` 不能同时满足 Node 与 Electron 的 ABI。顺序如下。

| 命令 | 结果 |
| --- | --- |
| `npm rebuild better-sqlite3`（切到当前 Node ABI） | 成功 |
| `npm test`（`node --test test/*.test.js`） | **55 通过 / 0 失败**，11 个套件，约 185 ms。含 `test/extension-popup-save.test.js` 与 `test/restore-close-pipeline.test.js`。 |
| `npm run check`（`node scripts/check-js.js` 逐文件 `node --check`） | **36 个 JS 文件全部通过**。不使用会只检查第一个文件的 `node --check` glob。 |
| `npm run rebuild`（切回 Electron 31 ABI）后 `npm run smoke` | 通过：已有 `DISPLAY` 下打印 `TRACEHUB_SMOKE_OK` 后自行退出。隔离临时 `TRACEHUB_USER_DATA`，`TRACEHUB_SMOKE=1` 且 `TRACEHUB_DISABLE_SYNC=1`，未导入真实浏览历史。有 dbus / GPU / GrabKey 等环境告警，与冒烟通过条件无关。**不是真实浏览器或 Windows 运行验证。** |
| `npm run pack:win`（`electron-builder --win nsis portable --x64`） | 在 Linux 上交叉生成 PE 产物，见下方哈希。`afterPack` 写入官方 win32-x64 Electron 31 `better-sqlite3` 预编译。**未在 Windows 真机运行。** |

测试实现使用临时 SQLite、临时 `127.0.0.1` HTTP 桥、进程内伪 IPC，并用 VM 加载真实扩展脚本、模拟 `chrome.windows` / `tabs` / `tabGroups`。**不能替代真实 Chrome / Edge GUI 的保存、恢复或关闭验收。**
