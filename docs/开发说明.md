# 拾迹 TraceHub 开发与安装说明

当前应用版本是 **1.2.4**（开发目录名仍可能是 `tracehub-1.2.1`）。本版在 1.2.3 之上增加合法、可逆的扩展「快捷安装」引导：一键打开扩展目录和 Chrome / Edge 官方扩展管理页，按 2–3 步加载已解压的扩展，配对成功后自动提示。不会静默安装，也不会写企业策略或改浏览器配置。以下 1.2.2 的构建、自测与打包说明仍然适用，版本号与产物文件名以 package.json 为准。

# 拾迹 TraceHub 1.2.2 开发与安装说明

- 原始 1.1.0 上传包、1.2.0 与含阻断的 1.2.1 产物应保留为历史副本，不要把 1.2.1 安装包当作本版。
- 本目录可能仍叫 `tracehub-1.2.1`（开发目录名可保留），但 **package.json / 扩展 manifest / 产物文件名均为 1.2.2**。
- 本版是待实机验收的加固测试版，不是功能全成熟声明。

## 环境

- Node.js 18+（本轮验证环境见 `docs/验收记录.md`）
- 本机开发：`npm ci`（或 `npm install`）后 `npm start`
- `better-sqlite3` 是原生模块：

```bash
# 跑 Electron（含 smoke / 日常启动）
npm run rebuild

# 跑 Node 单测前，把模块恢复为当前 Node ABI
npm rebuild better-sqlite3
npm test
npm run check   # 逐文件 node --check，不是只检查 glob 的第一个文件
```

同一套 `node_modules` 不能同时满足较新的 Node 与 Electron 31 的 ABI。请按要跑的目标重建。

本项目脚本：`start` / `test` / `check` / `rebuild` / `pack:win` / `smoke`。不要执行来路不明的安装脚本。

## 扩展（Chrome / Edge）

目录：`extension/`（Manifest V3，版本 1.2.2）。必须加载本目录的最新文件，不要用旧的 1.2.1 解压副本。

权限仅有 `tabs`、`storage`、`tabGroups`、`alarms`，以及 `http://127.0.0.1/*`。没有 Cookie、历史、debugger、nativeMessaging。

## 打包

```bash
npm ci
npm run rebuild
npm run pack:win
```

Linux 交叉打包会调用 `scripts/after-pack-win-native.js`，把官方 win32-x64 Electron 31 预编译 `better-sqlite3` 写入产物。交叉成功只说明 PE 文件格式和资源布局，不能写成已在 Windows 真机验证。

试用步骤见 `docs/Windows试用检查单.md`。
