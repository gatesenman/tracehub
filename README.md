# 拾迹 TraceHub

本机桌面应用（Electron）。把多款浏览器的**浏览历史**汇到一处，并在关机前把**真实已打开的页签**保存成可整理、可分批恢复的快照。

当前版本 **1.2.9**（修复安装版无法采集浏览器历史，并支持补采未开软件期间的历史；1.2.0 / 1.2.1 源码目录与旧产物另行保留，不要把旧安装包当本版使用）。统一名称是「拾迹 TraceHub」（不再使用 Browser History Hub 作为对外名称）。

## 它能做什么

- **多浏览器历史**：自动检测 Chrome / Edge / Brave / Vivaldi / Opera（Windows）/ Firefox 的多 Profile 历史，支持 Windows / macOS / Linux 的读取路径。需你在首次引导中勾选允许同步的配置后才会导入。
- **实时同步**：文件监听 + 轮询兜底 + 窗口聚焦同步；直接解析 SQLite WAL，Firefox 未 checkpoint 的访问也能读到。
- **时间树与今日总览**：按日 → 小时 → 域名浏览；今日页含 24 小时分布、会话、稍后读、时间黑洞等。
- **搜索**：关键词、时间词（昨天 / 近 7 天 / 上周…）、`site:域名`；可选 AI 语义搜索与「问历史」。
- **收藏与稍后读**：星标只收藏；稍后读需单独添加（右键）。收藏支持文件夹、导入浏览器书签、离线正文等。
- **可选 AI**：整理、每日摘要、报告、智能合集。未配置 Key 时用本地规则。Key 只存在本机 `config.json`，不进入渲染进程。设置里可以清除密钥。
- **页签快照 / 关机前整理**：可以从 Chrome / Edge **会话文件**手动读取当时已写盘的页签（无需扩展：先选配置、预览再保存；可能是旧档，不是此刻页签条）。扩展仍是可选增强，用于更接近实时的页签、按分组/固定恢复，以及按 tabId 核对后关闭。会话文件快照只能按窗口重新打开网址，不能按 tabId 关闭页签。默认不关浏览器。可本地预分类、去重、分批整理。可选 AI 补充网站用途与简介（默认只发送网址和标题）。
- **隐私**：暂停记录、域名黑名单（需确认）、噪音净化、备份恢复。自动截图与自动抓取正文**默认关闭**，暂停期间也不会跑。
- **导出**：历史可导出 CSV / JSON（文件名以 `TraceHub-` 开头）。快照可单独导出 JSON。

## 运行

需要 Node.js 18+（推荐 20）。

```bash
npm ci          # 或 npm install
npm run rebuild # 针对 Electron 31 重建 better-sqlite3（Node 单测请再用 npm rebuild better-sqlite3 恢复）
npm start
```

### 页签快照（Chrome / Edge）

**无需扩展（会话文件，1.2.7 起，1.2.8 加固）**

1. 打开「页签快照」，点击「从会话文件读取页签（无需扩展）」。
2. 选择 Chrome 或 Edge 的配置，先预览。界面会标明来源文件名、文件时间，以及是否因锁定而读到旧档。读不到时不会把空列表当成成功。
3. 确认内容后再保存。不会自动采集，也不会结束浏览器进程。刚打开、尚未写盘的页签可能不会出现。
4. 恢复时使用「按窗口重新打开网址」：在目标浏览器按原来的窗口分开打开 http(s) 网址。不能恢复标签分组、固定、窗口位置、登录状态或表单。不能按 tabId 关闭这些页签。一次打开 30 个及以上网址时会再确认一次；超过上限的网址会标明跳过，不会把整份快照都标成已恢复。

这不是 `chrome.tabs` 那种实时页签条。Edge / 部分 Chromium 浏览器在运行时可能独占锁定当前会话文件，此时只能读到较旧存档，或预览失败。导出的快照 JSON 只保留文件名和文件时间，不含完整磁盘路径。读取配置时会拒绝逃出用户数据目录的路径，以及指向配置外的符号链接（在 Windows 上也包括 junction，按规范解析后越界即失败）。

**可选：安装扩展（更接近实时、可按分组恢复、可按页签关闭）**

1. 在 TraceHub 的页签快照页或设置中，点击「打开扩展目录」，再点击「打开 Chrome 扩展页」或「打开 Edge 扩展页」。
2. 在浏览器扩展页打开开发者模式，选择「加载已解压的扩展程序」，选中刚才打开的目录（里面有 `manifest.json`）。应用不会替你静默安装扩展。
3. 点击「复制配对令牌」，在扩展选项页粘贴并点保存。请把扩展里的端口设成应用显示的监听端口（默认 17862；若被占用，应用会改用相邻端口并在界面标明）。选项页会向本机应用核对令牌：只有提示配对成功，才算连上。
4. 回到应用的「页签快照」查看、改分组、分批恢复。若要关闭这些页签，必须在应用里勾选风险说明并确认。

本应用不使用远程调试、不写企业策略、也不改浏览器配置来偷装扩展。本版也尚未上架 Chrome 网上应用店 / Edge 扩展商店。卸载时在浏览器扩展页移除即可。

**Firefox**：浏览历史同步可用；本轮**不能**从 Firefox 会话文件或扩展采集当前打开的页签，请使用 JSON 导入。

## 首次使用与数据位置

第一次启动会显示引导：勾选要读取历史的浏览器 / Profile，并选择是否开启自动截图、自动抓取正文（默认都关闭）。未完成引导前不会导入新的历史。同时会提示开启实时页签权限：只有在 Chrome 或 Edge 加载配套扩展并完成配对后，才能获取此刻打开的页签。选择稍后不影响历史同步和「从会话文件读取页签」。应用不会替你静默安装或改动扩展。

数据在应用的 userData 目录（安装版 Windows 一般为 `%APPDATA%/TraceHub/`，开发模式下可能仍带 `browser-history-hub` 目录名，取决于 Electron 的 `name` 字段）。统一库是 `hub.sqlite`，配置是 `config.json`，截图在 `thumbs/`，备份在 `backups/`。删除这些文件即可重置。若你以前用过旧名 BrowserHistoryHub，应用会尝试把旧库复制过来。

API Key 只保存在本机 `config.json`。页签快照的配对令牌也只用于本机 `127.0.0.1` 桥接。

## 关于「写回浏览器」和「恢复原状」

- 不能安全地写回各浏览器自己的历史库。
- 页签恢复是**重新打开网址**，不能恢复登录状态、未提交表单、滚动位置或页面内存。
- 不会接管操作系统的关机过程，只提供手动「关机前整理」入口。
- 不会强杀浏览器进程，也不会为了读会话文件而结束浏览器。扩展关闭页签时，网页自己的“未保存”提示可能不会出现，所以默认不关闭，确认时会明确告知。会话文件快照禁止按 tabId 关闭。

## 打包

```bash
npm ci
npm run rebuild
npm run pack:win   # 产出 TraceHub-1.2.9-setup.exe 与 TraceHub-1.2.9-portable.exe
```

`package.json` 目前只配置了 Windows 目标（NSIS 安装包 + portable）。macOS / Linux 可以用 `npm start` 跑源码，**不代表已提供或验证过这些平台的安装包**。在 Linux 上交叉打包时，`afterPack` 会把官方 win32-x64 Electron 31 预编译 `better-sqlite3` 换进产物；这只能证明产物文件格式完整，**不能**代替 Windows 真机运行验证。

命令面板默认入口是 **Ctrl+K**（不是 Alt+Space）。

## 技术栈

- Electron 31（主进程 + contextIsolation；渲染层为原生 JS）
- better-sqlite3（本机统一库）+ sql.js（只读解析被锁定的浏览器历史，含 WAL 合并）
- 可选 OpenAI 兼容 Chat Completions
- 配套 Chrome / Edge Manifest V3 扩展（官方 tabs / windows / tabGroups API）
